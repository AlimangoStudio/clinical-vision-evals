# Contributing

We welcome reproducible tests, synthetic reference fixtures, privacy-preserving format improvements, benchmark design and documentation. Before opening a PR:

- Agree not to submit patient records or clinical images, identifiable text, protected health information, licensed photographs without permission, medical device claims, API keys or private PAPPS source code.
- Run tests and public-artifact guard scripts.
- Include provenance and licensing for any future reference content.
- Do not introduce non-OpenAI API providers or alternative models. Keep the Codex-only policy in `AGENTS.md` and `docs/CODEX.md`.
- A medical condition reference is NOT a validated diagnosis classifier. If proposing one, first discuss research ethics and a validation plan rather than adding a patient image.

This project is not a venue for medical advice. Maintainers may decline submissions that pose clinical, licensing, or privacy risks.
