# OpenAI Codex Open Source Fund — project facts

Public project: `AlimangoStudio/clinical-vision-evals`.

Purpose: an independently usable, synthetic-only library and testing framework for developing and evaluating physician-reviewed multimodal observations and reference comparison workflows, without falsely claiming medical diagnosis.

Current functions: provenance-bearing example cases, descriptive overlap matcher, blank review worksheet, opt-in OpenAI Codex-only demonstration on a synthetic geometric image, automated tests and CI checks.

What grant resources would support: improving developer tests, documentation, contribution workflows, benchmark design, software security and reproducible evaluations in this **open-source repository**. PAPPS Doctor's Corner AI Vision and DailyQuest are distinct private commercial systems and are not presented as open source.
